# NAFS Grader

نظام مستقل لتصحيح اختبارات نافس وتحليل النتائج.

المشروع في مرحلة تأسيسية. تصحيح Excel متاح مبدئياً، ومحرك OMR يحتاج إلى تطوير واختبار بعينات فعلية.

Supabase project: `erqsricplegkowugkgwk`.

لا تضع مفاتيح سرية أو بيانات طلاب حقيقية داخل المستودع العام.

## تجربة OMR
من لوحة مدير النظام اختر المدرسة والاختبار المعتمد ثم «التظليل OMR». ارفع PDF أو صورة مسح ضوئي، ثم عاير عمود المادة بثلاث نقرات: أ للسؤال 1، د للسؤال 1، أ للسؤال 20. راجع هوية الطالب وكل قراءة قبل الاعتماد. لا تستخدم صورًا بمنظور مائل؛ المعايرة الحالية تصحح التحويل الخطي فقط.

القراءة تجريبية بعتبات ثابتة؛ الفارغ والمتعدد وغير المؤكد يتطلب قرارًا صريحًا. تحفظ القراءات وقرارات المراجع في قاعدة البيانات. الحفظ ذري ويرفض التكرار، ويستخدم صلاحيات مدير النظام الحالية. الصور تبقى داخل المتصفح ولا تحفظ على الخادم.

لقياس الدقة: جرب 10–20 ورقة مسح ضوئي متنوعة، وقارن كل إجابة بالتصحيح اليدوي. احسب نسبة القراءات المطابقة، نسبة الحالات المعلقة، وعدد القراءات الواضحة التي احتاجت تعديلًا. لا تعتبر اختبارات الصور المصطنعة قياسًا لدقة الأوراق الفعلية.
